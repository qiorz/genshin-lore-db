# exports · 导出

这里放从 `corpus/` 或 `db/` 生成的阅读版/表格。导出是**派生文件**，可以随时重建。

## 建议格式

```text
exports/
├─ by-region/
│  ├─ 蒙德.md
│  └─ 璃月.md
├─ by-character/
│  └─ 钟离.md
├─ timelines/
│  └─ 提瓦特编年史.md
├─ tables/
│  ├─ documents.csv
│  └─ coverage.csv
└─ reading-lists/
   └─ 主线阅读顺序.md
```

## 规则

- 文件名带生成日期或版本：`蒙德-2026-11-04.md`；
- 导出文件不手工改；要改改源文件；
- 公开分享前删掉大段原文，只保留索引/考据/短引用；
- 导出时保留来源和 `doc_id`，方便回查；
- 不要把 `raw/` 原样打包导出。

## 可能的导出

- 按地区/角色/版本的阅读清单；
- 按剧透等级的阅读顺序；
- 某实体的全部出现段落；
- 时间线；
- 覆盖统计 CSV；
- 给 Obsidian 的索引页。
