# 校对报告 · quest.obc.5299「第三章 第二幕 千朵玫瑰带来的黎明」

> 2026-11-05 · 触发：用户反馈「尾声」里掺入了序章 第三幕「巨龙与自由之歌」的内容。

## 1. 现象

`corpus/quests/archon/第三章 第二幕 「千朵玫瑰带来的黎明」.md` 的 `## 尾声` 节
（原第 850–955 行，106 行 / 3,249 字符）整段是蒙德序章第三幕尾声的剧情：
琴、芭芭拉、温迪、天空之琴、特瓦林、西风骑士团、愚人众「女士」。
与 3.0 须弥花神诞祭毫无关系。

与 `corpus/quests/archon/序章 第三幕 「巨龙与自由之歌」.md` 的 `## 尾声的尾声`
逐句对照，两篇有 75 行完全相同（省略号写法 `…` / `...` 略有差异）。

## 2. 根因链

1. **OBC 页面有正文，但渲染器没认出来。**
   `raw/official_site/obc/entries/5299.json` 的 56 个模块里**没有** `interactive_dialogue`，
   8 段完整剧情对话放在 `collapse_panel`（模块名「剧情对话」）的 `rich_text` 里，
   长度 1,848–8,458 字符。`render_quest` 只处理 `interactive_dialogue`，
   于是这批任务被判定为「OBC 无剧情」，进入 BWiki 补全流程。
2. **BWiki 只有 7 个子任务页，没有「尾声」。**
   缓存 `raw/bwiki/quest-transcripts/` 里能找到
   「终将到来 / 因果命运 / 空幻回响 / 流转存续 / 终将结束 / 轮回意志 / 已然来临」的花神诞祭页，
   没有对应「尾声」的页面。
3. **短名模糊匹配错配。**
   `fill_quests_from_bwiki.py` 的 `bwiki_page()` 用 `wanted in norm(candidate)` 做子串匹配。
   子任务名「尾声」（2 字）搜到了 BWiki 的「**尾声的尾声**」——那是蒙德序章第三幕的子任务页。
   缓存 `e0b053a7f893bfb9.json` 记录了这次错配：`title=尾声, page=尾声的尾声, revid=667050`。
   结果 front matter 写成「BWiki 补全任务剧情：8 个子任务页」，第 8 个就是错的那份。
4. 这与之前 `quest.obc.4190`（把别的邀约整篇塞进久岐忍）是同一类事故，
   上次已删掉「匹配不到取第一条」的回退，但**子串匹配本身**仍然会咬短通用名。

## 3. 修复

**用 OBC 主源重填，不再依赖 BWiki。** 新增 `scripts/repair_quest_5299_epilogue.py`：
从 5299 原始快照里定位以「最终妮露的舞蹈给大家带来了黎明」开头的 `collapse_panel`，
把 HTML 段落按现有 corpus 约定转换成 Markdown：

- `说话人：台词` → `**说话人**：台词`
- `<strong>` 短标题 → `### 标题`；长任务描述 → `> *旁白*`
- `<u>` 选项 → `> 选项（说话人）：…`
- `PS：…` 说明行与 `-----` 分隔线跳过

生成 95 行 / 3,418 字符的正确尾声（与凯瑟琳／纳西妲长椅对话、世界树、教令院、迪娜泽黛），
替换原 `## 尾声` 节，同步改写 `notes` 为「7 个子任务页 + OBC 尾声原文」。

**防再犯**

- `fill_quests_from_bwiki.py`：短名（≤3 字）必须精确相等才接受，
  只有 ≥4 字才允许子串匹配；加 `MANUAL_REVIEW = {"quest.obc.5299"}` 防止重跑覆盖人工校对结果。
- 删除错配缓存 `raw/bwiki/quest-transcripts/e0b053a7f893bfb9.json`，避免重跑时命中旧结果。

## 5. 同类排查（177 篇 BWiki 补全文档）

逐篇取出每个 `## ` 节标题，按 `sha1(标题)` 反查 BWiki 缓存的 `page` 字段，
共发现 **23 组「节标题 ≠ 实际来源页」**：

- **有实质内容且合理**（页面名只是加了系列前缀或空格/异体字差异）：
  `清籁逐雷记·其一~其四`、`献给某人的蔷薇·…` 等 8 组，台词 13–215 句，主题一致。
- **内容零碎、来源可疑但未整段串入**（11 组）：
  `1.5版本「玉扉绕尘歌」更新专题`（如「邀约事件·诺艾尔 第二幕」节里只有 `**神之眼**：冰`）、
  `金苹果群岛二期探索专题`（`**前往金苹果群岛大地图**：原神地图工具`）、
  `萨维特`、`婕德`、`阿赫玛尔的秘密`、`风暴捕物帐` 等。
  这些页面没有 `==任务剧情==`，补全脚本 fallback 抓到了导航/属性片段，
  每节 40–1,039 字符，**不是别的任务整篇串入**，暂不改动，留待逐篇人工核对。
- **`尾声 → 尾声的尾声`**：本次已修复，缓存已删。

全库按蒙德尾声特征台词扫描，命中文档只有 533（正确）和 5299（修复前），
**没有第三篇受污染**。

## 6. 遗留

- `render_quest` 仍只认 `interactive_dialogue`。OBC 把剧情放在 `collapse_panel` 的任务
  （5299 这类）会被误判为空、转去 BWiki 补全。要根治应给渲染器加 `collapse_panel` 剧情对话解析，
  但会影响 177 篇补全文档的既有正文，需单独评估后重渲染。
- 上述 11 组零碎错配节需要人工核对，建议在知识层建设时一并清理。
