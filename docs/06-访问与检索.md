# 访问与检索

数据库不是只能“打开文件看”。推荐按用途分四种入口。

## 1. 最快：命令行检索（推荐日常用）

在项目根目录：

```powershell
cd D:\harn\2\genshin-lore-db

# 全库搜
.\tools\python\python.exe .\scripts\search.py 白之公主

# 限定类型：book / lore / quest / character
.\tools\python\python.exe .\scripts\search.py 钟离 --type character
.\tools\python\python.exe .\scripts\search.py 葬火之战 --type book --limit 5

# 限定地区/剧透等级
.\tools\python\python.exe .\scripts\search.py 层岩巨渊 --region 璃月 --spoiler 1

# 机器可读，方便接脚本
.\tools\python\python.exe .\scripts\search.py 空月之歌 --json > result.json
```

特点：

- 搜正文 + 标题；
- 3 字以上走 FTS5 trigram；2 字词走 `sections_fts_words` 分词索引（有 bm25 排序），两套都没命中才回退 `LIKE`；
- 每条结果显示 `doc_id`、说话人、原文片段和来源 URL；
- 不依赖数据库 GUI。

## 3. 结构化查询：SQLite

命令行：

```powershell
.\tools\sqlite\sqlite3.exe -readonly .\db\genshin_lore.sqlite3
```

常用：

```sql
.tables
.headers on
.mode column

-- 按类型/地区列文档
SELECT doc_id, title, doc_type, region, version
FROM documents
WHERE doc_type = 'quest' AND region = '璃月'
ORDER BY version, doc_id
LIMIT 20;

-- 查某个词出现的段落
SELECT d.title, s.speaker, s.body
FROM sections s
JOIN documents d ON d.doc_id = s.doc_id
WHERE s.body LIKE '%钟离%'
LIMIT 20;

-- FTS5（3 字以上）
SELECT d.title, snippet(sections_fts, 1, '[', ']', '…', 20) AS hit
FROM sections_fts
JOIN sections s ON s.section_id = sections_fts.rowid
JOIN documents d ON d.doc_id = s.doc_id
WHERE sections_fts MATCH '"白之公主"'
LIMIT 10;
```

GUI 可以用 **DB Browser for SQLite** 打开 `db/genshin_lore.sqlite3`，适合点表、看 schema、导出 CSV。

注意：

- 不要把数据库当正文源手工改；正文以 Markdown 为准，改完重新导入；
- 只读打开用 `-readonly`，避免误写。

## 4. 程序调用：Python

```python
import sqlite3

con = sqlite3.connect(
    "file:D:/harn/2/genshin-lore-db/db/genshin_lore.sqlite3?mode=ro",
    uri=True,
)
con.row_factory = sqlite3.Row

rows = con.execute(
    """
    SELECT d.doc_id, d.title, d.doc_type, d.region, d.version
    FROM documents d
    WHERE d.doc_type = 'book' AND d.region = '蒙德'
    ORDER BY d.version, d.title
    """
).fetchall()

for row in rows:
    print(row["doc_id"], row["title"], row["version"])
```

## 5. 日常最舒服：本地 Web UI（已搭好）

启动：

```powershell
cd D:\harn\2\genshin-lore-db
.\webui\start.ps1
```

打开：

```text
http://127.0.0.1:8765/
```

功能：

- 搜索框：3 字以上中文走 FTS5 trigram，2 字词走 `sections_fts_words` 分词索引（带 bm25 排序）；
- 筛选：类型、地区、版本、剧透等级；
- 结果卡片：标题、类型、地区/版本、命中片段、来源；
- 文档页：正文、版本来源/置信度、来源链接、原始 Markdown；
- 只读：数据库以 `mode=ro` 打开，不会修改库或 Markdown。

接口：

```text
GET /health
GET /api/search?q=白之公主&type=book
GET /api/doc/quest.obc.2598
GET /raw/quest.obc.2598
```

技术实现是 `http.server + sqlite3 + markdown`，没有 Flask/FastAPI 依赖。  
只监听 `127.0.0.1`，不要改成 `0.0.0.0` 暴露到公网。

说明：[`webui/README.md`](../webui/README.md)

## 建议组合

| 场景 | 入口 |
|---|---|
| 快速查一句话/一个名词 | `scripts/search.py` |
| 连续读一本书/一段任务 | Obsidian 打开 `corpus/` |
| 统计、筛选、导出 | SQLite CLI / DB Browser |
| 写脚本、做知识层 | Python `sqlite3` 只读连接 |
| 日常最舒服 | `http://127.0.0.1:8765/` |
